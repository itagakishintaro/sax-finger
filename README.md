# Sax Finger

選んだ音の運指をサックスのイラストで表示するWebアプリ。

## 機能

- 五線譜上の音符をタップして音を選択する(記譜音 シ♭3〜ファ#6 のサックス全音域)
- 変化記号トグル([♭][♮][#])でシャープ・フラットの音を選択できる。異名同音(ド#=レ♭)はどちらからでも選択可能
- 選択した音の運指を、サックス全体のイラスト(SVG)上で押さえるキーを赤く着色して表示する
- 替え指のある音(シ♭・ド・ファ#)は運指トグルで切り替えられる
- 表記は記譜音のドレミ(カタカナ)のみ。対象はサックス族共通(汎用イラスト1種)
- PWA対応(ホーム画面に追加・オフライン利用可)

## 技術スタック

| 分類 | 技術 |
| --- | --- |
| フロントエンド | React 19 + TypeScript + Vite |
| スタイル | Tailwind CSS 4 |
| イラスト | インラインSVG(押さえるキーを `data-key` 属性付き要素として動的着色) |
| ユニットテスト | Vitest + Testing Library |
| 振る舞いテスト | Playwright + playwright-bdd(日本語Gherkin) |
| ホスティング | Firebase Hosting(完全静的。Firestore・Functions・Auth不使用) |
| CI/CD | GitHub Actions(PR時CI必須 / mainマージで自動デプロイ) |

## セットアップ

```bash
npm install
npm run dev   # http://localhost:5173
```

インフラ(Firebase / GCP / GitHub)の構築は `scripts/setup-infra.sh` を参照。
